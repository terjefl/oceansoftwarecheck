# Image sources

Assets owned by the Fisker Owners Association (FOA); used here with the association's
agreement for the Ocean Software Check portal.

- `foa-logo.png` – FOA community logo (266x100, transparent), from
  https://us1.discourse-cdn.com/flex001/uploads/fiskeroa/original/2X/2/2cbd2e788b8d18d038a1ef2cfada6ac45f23ebc7.png
- `foa-hero.webp` – front-page photo with the F/OA mark (1234x1200), from
  https://fiskeroa.com/wp-content/uploads/2024/12/foa-left-background.webp
- `../favicon.png`, `../apple-touch-icon.png` – F/OA mark rendered in Titillium Web Bold
  on #181818 (generated locally, not copied from the sites).

Fonts in `../fonts/` are Titillium Web (SIL Open Font License 1.1, see `OFL.txt`),
subset to Latin + Latin Extended-A from https://github.com/google/fonts/tree/main/ofl/titilliumweb.
